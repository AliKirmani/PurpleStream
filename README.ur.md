# Purple Stream — ونڈوز IPTV پلیئر

[English](README.md) · [تصاویر](README.md#gallery)

یہ Windows 10/11 کے لیے ایک الگ، اصل ڈیسک ٹاپ پروگرام ہے۔ اس میں اپنا Xtream Codes اکاؤنٹ یا M3U لسٹ شامل کریں۔ اس کے ساتھ کوئی چینل، سبسکرپشن یا ذاتی اکاؤنٹ فراہم نہیں کیا جاتا۔

## انسٹال کرنا

اس GitHub repository کے **Releases** حصے سے `PurpleStream-Setup-v0.4.3.exe` ڈاؤنلوڈ کریں۔ اسے کھول کر **Install** دبائیں۔ پھر Start Menu میں **Purple Stream** سے پروگرام کھولیں۔ روزانہ انسٹالر چلانے کی ضرورت نہیں۔ شارٹ کٹ پر رائٹ کلک کر کے Windows کی **Pin to taskbar** سہولت استعمال کر سکتے ہیں۔

پورٹیبل ZIP استعمال کریں تو اسے مکمل Extract کریں اور اندر `PurpleStream.exe` کھولیں۔ صرف EXE کو الگ منتقل نہ کریں۔

## استعمال

1. **Account** کھولیں، Xtream Codes یا M3U منتخب کریں اور اپنے فراہم کنندہ کی معلومات دیں۔
2. **Live TV، Movies، Series** میں ملک اور پھر کیٹیگری کھولیں، یا سرچ کریں۔ غلط ملک/کیٹیگری کو دستی طور پر درست کیا جا سکتا ہے۔
3. پسندیدہ پروگرام Favorites میں رکھیں۔ مووی یا قسط کے لیے پلیئر میں آگے پیچھے، آواز، فل سکرین اور دوسری دستیاب سہولتیں استعمال کریں۔
4. **Multiscreen** میں 2، 3 یا 4 سکرین منتخب کریں۔ ہر سکرین کا **Audio** الگ ہے؛ **Make main** سے مرکزی سکرین بنائیں۔ چینل منتخب کرنے میں ملک، کیٹیگری، سرچ، Favorites اور Recent استعمال کریں۔
5. مووی/قسط کو **Download** اور لائیو پروگرام کو **Record** سے محفوظ کریں۔ ریکارڈنگ ختم ہونے اور فائل مکمل ہونے کا انتظار کریں۔

ریکارڈنگ کے وقت **Stop preview to free a provider connection** منتخب ہو تو اسی پلیئر کی تصویر رک جاتی ہے۔ ساتھ دیکھنے کے لیے اسے غیر منتخب کریں، مگر اس کے لیے اکاؤنٹ میں ایک اضافی کنکشن دستیاب ہونا چاہیے۔ ملٹی سکرین بھی فراہم کنندہ کے کنکشن کی حد کے مطابق کام کرتی ہے۔

EPG کے لیے شیڈول اور Catch-up کے لیے پچھلے پروگراموں کا آرکائیو فراہم کنندہ کے پاس ہونا ضروری ہے۔ لائیو چینل میں آگے پیچھے کرنے کی سہولت ہر سٹریم میں نہیں ہوتی۔ تصاویر نمونہ لسٹ کی ہیں، اصل نشریات کی نہیں۔

یاد کیا گیا اکاؤنٹ اسی Windows صارف کے لیے مقامی طور پر انکرپٹ ہوتا ہے۔ شیئر کرنے کے لیے صرف اصل Release فائلیں دیں؛ اپنی playlists، settings، ریکارڈنگ یا اکاؤنٹ والی تصاویر شیئر نہ کریں۔ خرابی کی رپورٹ میں یوزر، پاس ورڈ اور مکمل سٹریم لنک نہ لکھیں۔

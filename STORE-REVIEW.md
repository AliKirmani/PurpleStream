# Store review sample

This playlist uses an original synthetic 20-second silent color animation generated by src/PurpleStream/tests/generate-fixture.cjs. It contains no TV broadcast, provider credentials or subscription. The test media and playlist are provided under this repository's MIT License.

In Account, select M3U and use https://raw.githubusercontent.com/AliKirmani/PurpleStream/main/store-review.m3u or download the playlist and choose its local file. Connect, then browse Live TV, Movies and Series. The channel is a finite test clip; reopen it after 20 seconds. Use the movie to test pause/seek/resume and downloads. Multiscreen can select the sample in several slots; the video has no audio. Audio tracks and EPG/catch-up require suitable authorized sources and are not demonstrated by this fixture.

This test source is not bundled in the app. Customers bring their own authorized sources.

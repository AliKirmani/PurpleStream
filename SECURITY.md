# Security policy

Only the latest published release is considered for fixes; no support period or response-time guarantee is offered. This is an independent community application.

Do not post credentials, playlists or exploitable vulnerability details in public issues. Use the repository's Security → Report a vulnerability feature if private vulnerability reporting has been enabled. If it is unavailable, open a public request for a private reporting channel without technical exploit details or personal information, and wait for a maintainer to provide one.

Include the version, Windows version, a minimal synthetic reproduction, affected component and impact. Never send your real subscription password. Dependency reports should identify the package and advisory. A maintainer should enable private reporting before promoting the repository.

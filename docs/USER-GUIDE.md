# User guide

## Connect

Open Account. For Xtream Codes, enter the server base URL, username and password provided by your service. For M3U, paste the full playlist URL or choose a local file. Remember account stores encrypted settings for your Windows user. Never publish these details in an issue.

Live TV loads first for Xtream accounts; Movies and Series load when opened. Refresh reconnects, and Cancel loading stops the current catalog operation. If authentication fails, check the base URL/port, subscription, account connection limit and whether the provider supports Xtream or M3U.

## Browse and watch

Choose a country and genre, or search titles. Favorites and recent history help locate frequently watched items. Manually correct a title's country/genre when provider naming is ambiguous. Open a series to choose its season and episode.

The player offers pause, seek bar, ±10-second movement, volume/mute, speed, available audio/subtitle tracks, fullscreen and snapshot. Keyboard: Space pauses; Left/Right seeks 10 seconds; Ctrl+Left/Right seeks 60 seconds; F opens fullscreen when an input control is not focused. Live seeking requires a seekable source.

## Multiscreen

Select 2, 3 or 4 screens and Equal screens or Main + sub screens. Choose / Play opens the country/category picker with search, favorites and recent filters. Each Audio: On/Off button represents the current state of that slot; screens begin muted. Make main selects the large slot. Reducing the screen count stops hidden slots. Ensure your provider allows the required simultaneous connections.

## Guide and catch-up

Use EPG for provider schedules, or set an XMLTV URL/file in Settings. Catch-up lists advertised archive-enabled channels. Select a past programme and Play archive. A channel without archives or a matching schedule cannot be made available by the app.

## Save video

Use Download on a movie or episode. Use Record for a live channel and choose a duration (0 means until stopped). The default Stop preview option frees a provider connection. Disable it only when your account permits simultaneous preview and capture. Monitor Downloads & recordings and stop there when finished. Wait for finalization; a .part file is incomplete. Exit requests stopping and finalizing active transfers.

## Settings and uninstall

Settings changes the XMLTV source, save folder and default volume. The installer can clear a previous local account/favorites/history when explicitly selected. Uninstall through Windows Installed apps. User data lives in `%LOCALAPPDATA%\PurpleStream`; saved media lives in your chosen video folder. Back up only information you intend to retain.

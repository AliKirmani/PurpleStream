# Purple Stream 0.4.3

Independent native IPTV player for Windows 10/11 x64. No channels, subscriptions or personal provider accounts are included.

- Xtream Codes and M3U login; country/genre browsing for Live TV, Movies and Series.
- Favorites, history/resume, full playback controls and encrypted local account/settings.
- Two, three or four playback screens, main/sub layout and independent audio.
- Faster multiscreen selection with country/category navigation, flags, search, favorites and recent items.
- EPG, provider-supported catch-up, movie/episode downloads and live recording.
- Original purple dashboard, icon, per-user setup, Start Menu and optional Desktop shortcuts.

Download **PurpleStream-Setup-v0.4.3.exe** to install, or extract the complete **PurpleStream-v0.4.3-Windows-x64.zip** for portable use. SHA256SUMS.txt lists integrity hashes; these are not a code-signing signature.

EPG/archives, seeking, recording formats and simultaneous connections depend on the source/provider. Recording stops preview by default to free a connection; disable that option only when another connection is allowed. No DRM bypass. See README and docs/FEATURES.md for full limitations. Validation used synthetic/local fixtures; real provider compatibility is not guaranteed.

This is an independent project, not an official Smart IPTV Stream Pro application. Application code: MIT; LibVLC: separate LGPL terms, retained in the distribution.
